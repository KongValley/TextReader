    自定义基座
    PDF 原样渲染，不受字体/字号/版心设置影响；Ctrl++ / Ctrl+- 缩放，Ctrl+0 适应窗口。

    使用说明

    • 打开与书架：拖文件进窗口、Ctrl+O 或菜单「文件」打开；把小说文件夹拖进窗口即加入书架，书架根视图右键可显示 / 刷新 / 移除文件夹；点书名开始阅读，阅读中按工具栏「书架」按钮或 Esc 返回书架。
    • 目录与跳转：Ctrl+T 开目录侧栏，点章节直达；书签 Ctrl+B 收藏当前页（列表内可 ✎ 重命名）；进度条可点击 / 拖动按全书比例直达，悬停可预览章节；Alt+← 回退上一次大跳转。
    • 划线与查找：选中文字 Ctrl+H 或右键「划线」，高亮随书保存；Ctrl+F 全文查找，Enter / Shift+Enter 下一处 / 上一处。
    • 阅读模式：翻页（← → / 空格 / 鼠标侧键）与滚动（滚到底自动进下一章）在设置里切换；Ctrl+滚轮 调字号（PDF 为缩放，Ctrl+0 适应窗口）。
    • 自动阅读与提醒：F5 开关自动阅读，+ - 调速，任意操作停止；「久坐提醒」在设置里开启后连续阅读 45 分钟提示休息；已读时长按书累计显示在状态栏。
    • 进度记忆：阅读位置、书签、划线、时长按文件路径自动保存；文件移动 / 改名后，同名同大小的新文件自动沿用原记录。
    • 更新：菜单「帮助 > 检查更新…」手动比对 GitHub 最新版本（平时不联网）。

    快捷键

    • Ctrl+O 打开文件
    • Ctrl+T 目录
    • Ctrl+F 查找
    • Ctrl+B 添加书签
    • Ctrl+, 阅读设置
    • ← → / PgUp PgDn 翻页
    • 空格 下一页 / 下一屏
    • Home End 全书首 / 尾（PDF 为首 / 末页）
    • Ctrl+PageUp/PageDown 上/下一章（PDF 为上/下一页）
    • Ctrl++ / Ctrl+- TXT 字号 / PDF 缩放
    • Ctrl+0 PDF 适应窗口
    • Ctrl+滚轮 TXT 字号 / PDF 缩放
    • Alt+← 返回上次跳转前位置
    • Enter / Esc 密码框：解锁 / 取消
    • F11 全屏，Esc 关闭面板；阅读中再按返回书架
